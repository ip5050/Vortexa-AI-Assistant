# Vortexa AI Assistant 🤖

Vortexa AI is a lightweight, web-based virtual assistant powered by **Groq Cloud (Llama/Gemma models)** and **Serper.dev** for real-time web search integration.

## Features
- 🚀 **Real-time AI Chat**: Powered by high-speed Groq inference.
- 🔍 **Web Search Context**: Fetches live data from Google for accurate answers.
- 📱 **Mobile Responsive**: Clean and modern UI/UX.
- 💾 **Session Memory**: Remembers previous context within the session.

## Setup
1. Clone the repository.
2. Open `process.php` and replace `YOUR_SERPER_API_KEY_HERE` and `YOUR_GROQ_API_KEY_HERE` with your actual keys.
3. Host on any PHP-enabled server (Requires cURL extension).
